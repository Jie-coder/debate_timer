# 辩论计时器

这是一个本地可运行的辩论计时器。当前仓库采用「方案 C」结构：源码拆成 `index.html`、`style.css`、`app.js`，再按需打包成单 HTML。

## 快速使用

直接打开：

- `index.html`

或使用本地服务器：

```powershell
python -m http.server 8017 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8017/index.html
```

## 常用命令

```powershell
npm run check
npm run build
```

`npm run build` 会生成：

- `dist/debate-timer.single.html`
- `辩论计时器（bj）.html`

## 当前功能

- 首页封面：可编辑比赛赛段、辩题、正方学校、反方学校。学校名较长时（约 15 个汉字）对阵区自动加宽、字号自动缩小，正反方始终用同一个字号。
- 单计时：固定大尺寸显示。
- 双计时：正反双方各一个计时器，界面只显示「正方 / 反方」，不显示学校名。
  每个双计时环节可选两种结束行为，在设置抽屉的环节行上点徽章切换：
  - **交锋**：一方时间用完自动接续对方，用于自由辩、对辩、攻辩。
  - **独立**：一方用完就停，对方剩余时间原地保留，用于正反双方各自质询、申论。
  没手动设过的环节按环节名自动判断，改名后默认值跟着变。
- 设置抽屉：主题、字体比例、环节流程、最多 3 个计时器预设、声音（开关、音量拉杆、最后 10 秒逐秒音）、快捷键。
- 自定义背景：在「设置 → 外观 → 背景图片」选择本地 JPG、PNG 或 WebP（最大 10 MB），首页和所有计时环节都会使用该背景。图片居中铺满，边缘可能被裁切；保留主题配色和半透明底色以便阅读，可随时恢复默认背景。
- 背景图片只在浏览器本地处理，最长边缩至 1920 像素后单独保存，刷新后保留。存储空间不足时会提示仅本次使用；图片不会随单 HTML 文件导出，也不会上传到服务器。
- 分享赛制：在「设置 → 分享赛制」点「分享赛制」复制一段以 `DT1.` 开头的代码，对方粘贴到同一处的输入框点「导入」即可得到同样的环节。代码只含环节名称、时长、单 / 双计时和交锋 / 独立，不含主题、背景、辩题和队伍；连同聊天里的其他文字一起粘贴也能识别。
- 手机和平板：竖屏时环节导航横向滑动、双计时上下排；手机横屏时页头和底栏各压成一行；触屏上按钮可点范围加大。规则集中在 `style.css` 末尾的「平板 / 手机适配」一节。
- 本地存储：使用 `localStorage` 保存设置、流程、辩题、学校和预设。

## 已删除功能

以下功能已经从源码中移除，后续维护不要恢复旧分支：

- 环形显示模式。
- 计时器大小调节。
- 旧状态字段 `display`、`timerScale` 的实际使用。

旧 `localStorage` 如果带有这些字段，载入后会清理并重新保存。

## 文件说明

- `index.html`：页面结构，引用外部 CSS/JS。
- `style.css`：完整样式。
- `app.js`：应用状态、渲染、事件、计时逻辑。
- `scripts/build-single.js`：把源码打包成单 HTML。
- `scripts/check.js`：无依赖健康检查。
- `scripts/test-duel-flow.js`：无依赖行为测试，覆盖双计时的交锋 / 独立逻辑。
- `dist/`：构建产物。
- `legacy/bundled-legacy.html`：方案 C 重构前的原始打包文件，仅用于回滚参考。

## 开发原则

- 优先改源码文件，不直接改 `dist/` 或 `辩论计时器（bj）.html`。
- 改完后运行 `npm run check`。
- 需要交付单文件时运行 `npm run build`。
- 不引入框架，除非明确需要。
